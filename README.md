# Minha Rua

Diretório público de casas em São José do Belmonte — PE.

A pessoa cadastra a casa (foto + endereço completo). Qualquer pessoa encontra
por rua, bairro, número, morador ou coordenadas.

## Estado

Protótipo visual em `index.html` (sem persistência). O MVP usará Firebase Spark.
